ADAPTIVE SCALE-AWARE PANOPTIC SEGMENTATION WITH BOUNDARY REFINEMENT
=================================================================

PROJECT OVERVIEW
----------------
A comprehensive ML project implementing a novel panoptic segmentation approach
that combines adaptive scale-aware feature fusion with boundary refinement for 
improved multi-scale object segmentation on COCO 2017 dataset.

NOVEL CONTRIBUTIONS
-------------------
1. Adaptive Scale Fusion Module
   - Uses multi-head self-attention to dynamically weight features from different FPN levels
   - Allows adaptive focus on appropriate scales for objects of different sizes
   - Location: src/.../models/components.py:84 (class AdaptiveScaleFusion)

2. Boundary Refinement Module
   - Predicts learned distance transforms and boundary maps
   - Improves segmentation quality at object boundaries
   - Location: src/.../models/components.py:13 (class BoundaryRefinementModule)

3. Combined Panoptic Loss
   - Custom loss combining semantic, instance, boundary, and panoptic objectives
   - Uses Focal Loss and Dice Loss for class imbalance
   - Location: src/.../models/components.py:270 (class CombinedPanopticLoss)

SCRIPTS
-------
1. scripts/train.py
   - Full training pipeline with MLflow tracking
   - Checkpoint saving and resuming
   - Configurable via YAML files
   - Supports --config flag for different configurations

2. scripts/evaluate.py
   - Loads trained model from checkpoint
   - Computes multiple metrics: PQ, SQ, RQ, Boundary IoU
   - Per-class analysis
   - Visualization support with --visualize flag
   - Saves results as JSON and CSV

3. scripts/predict.py
   - Inference on single images
   - Outputs predictions with confidence scores
   - Saves semantic, instance, and boundary masks

CONFIGURATIONS
--------------
1. configs/default.yaml
   - Full model with all novel components enabled
   - use_boundary_refinement: true
   - use_scale_adaptive_fusion: true

2. configs/ablation.yaml
   - Baseline model without novel components
   - use_boundary_refinement: false
   - use_scale_adaptive_fusion: false
   - For comparing contribution of novel components

USAGE EXAMPLES
--------------
# Train with default config
python scripts/train.py

# Train with ablation config (baseline)
python scripts/train.py --config configs/ablation.yaml

# Resume training
python scripts/train.py --resume checkpoints/best_model.pth

# Evaluate model
python scripts/evaluate.py --checkpoint checkpoints/best_model.pth --visualize

# Run prediction
python scripts/predict.py --image path/to/image.jpg --checkpoint checkpoints/best_model.pth

# Run tests
pytest tests/ -v --cov=src
